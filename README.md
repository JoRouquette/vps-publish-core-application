# @core-application — Publish to VPS

Application layer of the [Publish to VPS](https://github.com/JoRouquette/obsidian-vps-publish) stack: use cases, handlers, and orchestration services shared by the Obsidian plugin and the self-hosted API. Depends on [`@core-domain`](https://github.com/JoRouquette/vps-publish-core-domain).

> **Read-only mirror.** This repository is regenerated from the monorepo on every stable release — do not open pull requests here.
